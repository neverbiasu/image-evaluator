CLI 发现命令调用范式 Command Syntax

支持子命令直觉输入与全局参数输入，完全兼容现有 --metrics 评测流程。 

# 1. 列表查看全量 10 项评估指标
image-evaluator list
image-evaluator --list-metrics

# 2. 按任务与评估目标过滤
image-evaluator list --task image_editing
image-evaluator list --objective pixel_fidelity
image-evaluator list -t image_reconstruction -o pixel_fidelity

# 3. 详细查看单一指标规格（纯文本 / JSON）
image-evaluator show directional_clip
image-evaluator show directional_clip --format json

# 4. JSON 管道流水线（供 jq 消费）
image-evaluator list --format json | jq '.[].id'

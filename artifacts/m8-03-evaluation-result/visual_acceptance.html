双通道 API 设计：兼顾极简与深度分析 Dual-Channel API

M8-03 为 Python 调用方提供了平滑过渡能力：默认保留最轻量的纯字典返回，同时提供结构化结果对象。 

# 通道 1：既有极简字典返回（完全向后兼容，默认行为）
res_dict = evaluate(img, reference=ref, metrics="ssim")
# res_dict -> {'ssim': 1.0}

# 通道 2A：标记参数获取 EvaluationResult
res_obj = evaluate(img, reference=ref, metrics="ssim", detailed=True)

# 通道 2B：专属显式函数获取 EvaluationResult
res_obj = evaluate_detailed(img, reference=ref, metrics="ssim")
# res_obj['ssim'] -> 1.0 (Mapping 协议直接取值)
# res_obj.specs['ssim'].score_direction -> 'higher_is_better'
# res_obj.to_json() -> RFC 8259 合规纯净 JSON 字符串
EvaluationResult 核心属性与契约 Rich Contract
成员 / 方法 类型 / 签名 说明与设计原则
scores dict[str, float] 纯净数值结果字典，防篡改浅拷贝隔离
specs dict[str, MetricSpec] 从 Registry 绑定的指标完整规格元数据
inputs dict[str, Any] 本次执行的入参画像（类型、设备、Prompt）
duration_seconds float 精准评测耗时审计（基于 perf_counter）
__getitem__ / get Mapping[str, float] 完全兼容 res["ssim"] 既有字典取值习惯
to_dict() dict[str, float] 导出标准浮点数结果字典
to_json() str 严格 RFC 8259 规范，非有限值自动转 null
Mapping 协议兼容性与防御性校验 Protocol Guard
  • ✓
    下标与成员检测：
    支持 res["ssim"]、"ssim" in res、len(res) 及迭代。
  • ✓
    不可变性保障：
    基于 @dataclass(frozen=True, slots=True)，防外部非法属性注入。
  • ✓
    数值与类型防线：
    指标名必须为字符串，分值必须为浮点数，耗时必须为非负数。
  • ✓
    RFC 8259 序列化防崩溃：
    PSNR 等指标可能出现的无穷大自动安全归一化为 null。
轻量级顶层导入与按需加载隔离 Zero Heavy Imports

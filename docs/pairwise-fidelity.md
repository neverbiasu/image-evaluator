# Pairwise Fidelity Metrics: LPIPS, SSIM, PSNR

## Facts

| Property | LPIPS | SSIM | PSNR |
| :--- | :--- | :--- | :--- |
| **Category** | Deep Perceptual Similarity | Structural Statistics Similarity | Pixel-level Peak Signal-to-Noise Ratio |
| **CLI Metric** | `lpips` | `ssim` | `psnr` |
| **Inputs** | `--image`, `--reference` | `--image`, `--reference` | `--image`, `--reference` |
| **Output** | Distance float in `[0.0, +inf)` | Similarity float in `[-1.0, 1.0]` | Decibels (dB) in `[0.0, +inf)` |
| **Direction** | **Lower is better** (0.0 = identical) | **Higher is better** (1.0 = identical) | **Higher is better** (+inf = identical) |
| **Backbone / Spec** | Official `lpips` v0.1 (AlexNet trunk) | Wang et al. 2004 ($11 \times 11, \sigma=1.5$) | $10 \cdot \log_{10}(\text{MAX}^2/\text{MSE})$, $\text{MAX}=1.0$ |
| **Source** | [richzhang/PerceptualSimilarity](https://github.com/richzhang/PerceptualSimilarity) | Wang et al. IEEE TIP 2004 | Standard Signal Processing Definition |

---

## Semantic Complementarity

The triad of pairwise fidelity metrics covers distinct levels of image representation:
1. **LPIPS (Perceptual Deep Feature Layer)**: Measures human-perceived distance using multi-scale deep activations. Highly tolerant to minor color shifts and small noise, but sensitive to semantic and textural distortions.
2. **SSIM (Structural Statistical Layer)**: Measures structural degradation based on local luminance, contrast, and structural covariance across an $11 \times 11$ Gaussian neighborhood.
3. **PSNR (Raw Pixel Fidelity Layer)**: Measures pixel-by-pixel squared differences. Highly sensitive to subtle global offsets (such as brightness shift or slight color tint), providing a strict baseline for numerical reconstruction.

---

## Size Matching & Fail-Fast Policy

Pairwise metrics require exact spatial dimension alignment ($H_{\text{ref}} = H_{\text{gen}}$ and $W_{\text{ref}} = W_{\text{gen}}$).

- **Fail-Fast Error**: If input dimensions differ, `image-evaluator` strictly raises `ValueError` and terminates immediately. It will **never** perform implicit or silent interpolation.
- **Minimum Dimension Boundary (SSIM)**: SSIM requires spatial dimensions to be at least the Gaussian window size ($11 \times 11$). Images smaller than $11 \times 11$ (or rectangular images where either width or height is $< 11$) cannot be scored and will strictly raise `ValueError`.
- **Pre-processing Guidance**:
  - **Academic Benchmarks**: When comparing models at differing native resolutions, align sizes beforehand using anti-aliased downsampling (e.g. PIL `Image.Resampling.LANCZOS`) to avoid hallucinating synthetic high frequencies.
  - **Super-Resolution Benchmark Evaluation**: Standard super-resolution reconstruction evaluation must compare generated outputs against registered high-resolution (HR) ground-truth images. Do not use another super-resolution model (such as Real-ESRGAN or HAT) to generate reference images and treat them as ground truth. If a synthetic reference generated by an external model is used in non-ground-truth settings, it must be explicitly declared as a surrogate / proxy comparison rather than standard ground-truth reconstruction evaluation.

## Numerical Protocols & Aggregation

1. **RGB Color Space Conversion**:
   All input images are converted to 3-channel RGB via `Image.open(...).convert("RGB")` before tensor conversion, ensuring consistent evaluation across grayscale, RGB, and RGBA image formats.
2. **SSIM Multi-Channel Computation**:
   SSIM is computed per channel using the Wang et al. (2004) $11 \times 11, \sigma=1.5$ Gaussian window, border padding is cropped (`pad:-pad`), and the unweighted arithmetic mean across all three RGB channels is returned.
3. **Directory Batch Aggregation**:
   When evaluating directories, scores across all successfully paired image pairs are aggregated using the unweighted pairwise arithmetic mean (`np.mean(scores)`).
4. **PSNR Infinity Behavior**:
   When an evaluated image pair is strictly identical, pixel MSE is 0.0, yielding $\text{PSNR} = +\infty$ (`float("inf")`). Under the existing directory pairwise arithmetic mean aggregation (`np.mean`), if even a single pair in a directory evaluation produces `+inf`, the directory average PSNR mathematically evaluates to `+inf` (`inf`). The existing approved aggregation protocol is preserved without adding new flags or altering calculation formulas.

---

## Directory Batch Pairing Contract

When both `--image` and `--reference` are directories:
1. **Exact Stem Matching**: Files are paired by case-sensitive stem (ignoring extensions, e.g. `sample_01.png` pairs with `sample_01.jpg`).
2. **Strict Completeness**: If any stem in `--reference` is missing in `--image` (or vice versa), the process immediately halts with `FileNotFoundError`.
3. **Zero Partial Batches**: Any unreadable file or size mismatch fails the entire batch evaluation.

---

## Invocation Examples

1. **Single Pair**:
   ```bash
   image-evaluator --metrics lpips ssim psnr \
       --reference path/to/reference.png \
       --image path/to/generated.png
   ```

2. **Directory Batch**:
   ```bash
   image-evaluator --metrics lpips ssim psnr \
       --reference path/to/reference_dir/ \
       --image path/to/generated_dir/
   ```
